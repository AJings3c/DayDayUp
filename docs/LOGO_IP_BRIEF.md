# DayDayUp Logo 与小松鼠 IP 设计简报

## 1. 项目背景

DayDayUp 是一个 macOS 原生学习执行监督工具。

它不是普通打卡应用，也不是学习路线生成工具。用户会自己制定学习任务，应用负责监督任务执行：倒计时、提醒、进度记录、任务日历、数据评分、学习历程和任务闭环复盘。

产品气质是：

- 安静
- 专注
- 克制
- 原生 macOS
- 有一点轻快的生活感

核心完成文案是：

> 任务完成啦，开始干饭！

## 2. Logo 核心概念

Logo 主体是一只生动活泼的小松鼠。

小松鼠不是单纯可爱吉祥物，而是 DayDayUp 的产品灵魂：

- **持续积累**：松鼠一点点收集松果，就像用户每天积累知识、代码、项目经验和复盘记录。
- **敏捷行动**：松鼠灵活、反应快，对应用户快速进入任务、开始专注、完成记录。
- **长期准备**：松鼠为冬天储备松果，对应用户从小白成长为专业开发者的长期路线。
- **自我驱动**：松鼠自己收集、自己整理，代表用户自己规划、自己执行、自己监督。

可以把“小松果”理解为用户完成的一个个学习任务。

## 3. Logo 视觉方向

目标：适合 macOS 原生应用图标，同时保留小松鼠的生命力。

建议方向：

- macOS 应用图标风格，圆角方形底板。
- 小松鼠作为主体，轮廓清晰，表情灵动。
- 可以让小松鼠抱着一颗松果，表达“任务完成”和“积累成果”。
- 小松鼠可以有轻微半立体质感，但不要做成夸张 3D 玩具。
- 背景可以有轻微 Liquid Glass / 玻璃质感，但必须克制。
- 缩小到 32px 时仍然能识别是松鼠和松果。

推荐构图：

1. **主 Logo 图标**
   小松鼠抱着松果，站在圆角方形 macOS 图标底板中，表情开心但不幼稚。

2. **任务完成状态图标**
   小松鼠抱着松果笑脸盈盈，表达“任务完成啦，开始干饭！”

3. **逾期提醒状态**
   小松鼠轻微闹脾气，抱着空篮子或看着倒计时，表达任务还没收进篮子。

4. **逾期后补完成状态**
   小松鼠抱着松果，旁边可以有紫色小标记，表达“晚了一点，但已经补上”。

## 4. 小松鼠 IP 性格

小松鼠的性格关键词：

- 聪明
- 灵活
- 有精神
- 自律
- 有一点小脾气
- 不吵闹
- 不卖萌过度

它像一个认真收集松果的小伙伴，会提醒用户任务还没完成，但不会责备用户。

它的情绪表达要克制：

- 完成任务：笑脸、抱着松果、满足。
- 未完成但未逾期：有点着急，看倒计时，抱着空篮子。
- 逾期未完成：闹一点小脾气，跺脚，尾巴炸开，但不要凶。
- 逾期后补完成：松一口气，抱着松果，旁边带紫色状态提示。
- 没有任务：抱着空篮子，期待用户放入第一颗松果。

## 5. 颜色建议

主色应保持安静克制，不要做成大面积橙色松鼠主题。

推荐颜色：

- 感知蓝：`#3F6FA8`，用于主品牌、系统感、任务监督感。
- 深夜蓝：`#18324D`，用于高可信度、重要数字和深色细节。
- 松鼠铜：`#B56A2A`，用于小松鼠毛色和品牌温度。
- 松针绿：`#247C5E`，用于按时或提前完成。
- 克制红：`#B54848`，用于逾期未完成。
- 补完成紫：`#7A5CCF`，用于逾期后补完成。
- 主背景：`#FFFFFF` 或接近纯白。
- 面板浅灰蓝：`#F6F8FB`。

颜色使用原则：

- 小松鼠本体可以用松鼠铜和浅棕色。
- 背景和界面气质保持白色、浅灰蓝、感知蓝。
- 绿色、红色、紫色只作为任务状态色，不要抢走 Logo 主体。

## 6. 禁止方向

不要做成：

- 幼儿贴纸风。
- 夸张卡通表情包。
- 过度 3D 玩具风。
- 赛博朋克松鼠。
- AI 科技感发光松鼠。
- 大量紫色渐变、霓虹、发光边缘。
- 复杂背景插画。
- 社交打卡应用的奖章、积分、排行榜风格。
- 普通橙色动物头像，没有学习监督和任务积累含义。

- 不要赛博朋克。

- 不要大量渐变。
